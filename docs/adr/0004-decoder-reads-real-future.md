# In joint training the decoder reads the real future latent, blurred to the predictor's accuracy

Implemented by ticket 008 behind `decoder_hint = "real"` (preset `joint-real-hint.json`); it becomes the default only if the gate in `RUNS.md` §0b passes. Supersedes the gradient paths of ADR 0002 for the joint JEPA stage when `decoder_hint = "real"`; ADR 0002 stays the recipe for `decoder_hint = "committed"` (the default until the gate in ticket 008 passes). ADR 0003 (random hidden horizon) is unchanged.

The random-horizon joint run (`runs/random-joint-seed1`, `decoder_w = 0.3`, 3 epochs) removed the periodic shortcut (max rebound 0.0009, slot-horizon mutual information 0.0001 nats) but not the reason the encoder finds shortcuts: nothing rewards it for content. Document identity now explains 81% of the latent's variance (0.22 two-stage, 0.60 joint with fixed k), effective rank fell from 41 to 26, and the decoder cannot tell the hindsight commit from the π-argmax commit (0.002 nats apart). Three gradient paths explain it:

- **The JEPA target is detached, and the move loss pulls z_t toward it.** The prediction loss reaches the encoder only through the input z_t: "make z_t predictive of whatever z_{t+k} already is". Candidates are z_t + δ, so besides the trunk the move gradient has a direct identity path that pulls z_t itself toward z_{t+k}: an active reward for slowness, not only an absence of a reward for content. The slowest thing in text, the document, is the cheapest answer.
- **The decoder gradient through z_t (ADR 0002) rewards long-range context.** The decoder already sees the last 32 tokens, so z_t is paid for what that window lacks: topic, style, which document this is. It pushes toward the per-document code, and the measured document share rose when it was added.
- **Candidates are chosen by latent distance.** In a document-shaped latent they split along whatever variance is left, not along differences that change the text.

So in the joint JEPA stage the decoder's hint becomes (z_t detached, z_{t+k} real plus noise), and the token loss reaches the encoder only through the block-end latent z_{t+k}. That latent has read the whole block, so the loss is a reconstruction: z_{t+k} is rewarded for summarizing the block. Because z_t and the 32-token window already provide context and the next-token prediction, z_{t+k} is paid only for the block's new content. That is the information the JEPA target should carry. Predicting z_{t+k} then means predicting what the next stretch of text says, which has several genuine answers: the job the candidates and π were built for. The encoder does not know where a block started (k is hidden, ADR 0003), so it learns a summary of roughly the last 10 to 30 tokens, weighted toward the recent ones, with no k involved.

Reconstruction always gains from more detail, and the detached JEPA target never charges z_{t+k} for being hard to predict. 448 floats can come close to storing 30 tokens outright, so without a limit the latent becomes a surface hash that no candidate can cover. The limit is noise on the decoder's copy: ẑ = z + s · (‖z‖ / √D) · ε, ε ~ N(0, I), with s chosen so that the expected cosine distance between ẑ and z equals the batch's hindsight distance (detached): s² = 1 / (1 − d/2)² − 1. VISReg pins the latent's scale, so the encoder cannot drown out the noise by growing its signal. The decoder is then trained at about the precision it will get at inference, so only detail that survives prediction error is worth storing, and the gap between training on real latents and decoding from candidates mostly closes. The noise follows the predictor, so it adds no hyperparameter.

The committed future is no longer part of the joint objective. The predictor is trained by the commitment loss alone, as in ADR 0002. A decoded hindsight or π commit stays an evaluation condition. The decoder stage (frozen JEPA, committed hints) is unchanged.

Alternatives considered:

- **A bag-of-words head on each latent** (predict the words of the last W tokens). Same reward for content, but it adds a head that inference never uses, and the decoder still learns to read committed hints instead of the latents it is meant to render.
- **Let the JEPA gradient flow into the target**, so predictability limits what the latent stores and `decoder_w` is the balance between reconstruction and predictability (β-VAE-like). More principled, but it pays the encoder for being slower, which is the failure being fixed, and the balance sits on one weight. Every commitment term (move, μ, π, diversity) would also start training the encoder, and only VISReg would prevent collapse. Kept as the fallback, restricted to the move term (ticket 008).
- **Decoder gradient through the committed candidate into the predictor**, with the winner chosen by decoder loss instead of latent distance (a discrete latent-variable language model). Tests the commitment claim most directly but costs up to P decoder passes and reopens ADR 0002's train/inference gap. A later decision.
- **Contrast each prediction against the document's other blocks** (InfoNCE). Kills the per-document code, but a causal encoder can count tokens, so position alone separates the blocks.
- **Require variance within each document.** Forbids the symptom; position or other cheap variation satisfies it without content.
- **A larger predictor or more slots.** Six of eight slots are already dead. The reward is unchanged.
- **Distill a pretrained sentence encoder.** Semantics by definition, but it turns the method into distillation. Used as an independent probe instead.

Accepted costs and open risks:

- **The latent may become lexical rather than semantic.** The cross-entropy rewards exact surprising tokens (names, numbers). Predictable function words cost the latent nothing, which helps, but the noise level decides how abstract the summary is. The next-block probe in `measure` checks it.
- **The noise is isotropic.** It limits the latent evenly, not by how predictable each part is, so coarse but unpredictable content (what the next sentence is about) survives. That is the multimodal future the candidates exist for, so we accept it.
- **The move loss still rewards slowness.** This decision adds a reward for content but leaves the direct pull of z_t toward z_{t+k} through the residual candidates in place, so the two compete. If the per-document code persists, the narrowest next step is to detach z_t in the residual (candidates = sg(z_t) + δ), so the move loss trains only the predictor. A separate decision (ticket 009).
- **The block-start latent z_t gets no decoder gradient.** Every position is some block's end at some k, so every latent is still trained to summarize.
- **The decoder's `real` condition is now the training condition.** `measure`'s `real`, `hint_use` and `z_t_use` change meaning, and runs with the two hint modes compare only through the conditions both report.
- **The recipe changes again after results.** As in ADR 0003, the report's hypotheses keep their wording and the report states the change.
